SLOT RACING – PWA TESTBUILD 0.3

Dateiübersicht:
- index.html: Renn-App
- manifest.json: Installierbare Web-App
- sw.js: Offline-Grundcache / App-Update
- icon.svg: App-Symbol

GitHub Pages:
1. Ein neues öffentliches Repository erstellen.
2. Alle vier Dateien direkt in den Hauptordner hochladen.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Die veröffentlichte HTTPS-Adresse in Chrome auf dem Xiaomi Pad 7 öffnen.
5. Kamerazugriff erlauben. In Chrome-Menü ggf. „App installieren“ oder „Zum Startbildschirm hinzufügen“.

WICHTIG:
Dies ist ein früher Test-Prototyp. Er zählt pro kalibrierter Farbe erkannte Überquerungen der waagerechten Start-/Ziellinie. Es gibt noch keine robuste Mehr-Objekt-Verfolgung bei Überdeckungen und keine automatische Kalibrierung der Streckenrichtung. Für verlässliche Messungen bitte zunächst mit einem Fahrzeug testen. Kamera benötigt HTTPS.
